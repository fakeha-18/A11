# A11 - Town Hall Responsive Design

For this assignment, I used my previous Town Hall website and updated it to make it responsive for different screen sizes.

I worked on the HTML and CSS to make sure the website looks good on both computers and smaller screens. I also added a mobile navigation menu that appears when the browser window gets smaller.

I made sure the images adjust to the screen size and that the content is easier to read on mobile devices. I also kept the speaker pages, pictures, and navigation links from the previous assignment.

After making the changes, I tested the website by resizing my browser window and checking that the navigation menu, dropdown options, images, and links were working properly.
