# A11 – Town Hall Responsive Design

For this assignment, I used my Town Hall files from A09 and updated the layout to work better on smaller screens. The main content stacks into one column on a phone, the pictures resize, and the desktop navigation switches to a SlickNav mobile menu with submenus.

The project includes `index.html`, the `styles/main.css` file, speaker pages in `speakers`, and photos in `images`. I also updated the copyright footer with my name and the A11 due date.

I tested the local HTML pages in a browser. Before submitting, I need to check the GitHub Pages version on both a wide and narrow screen.
